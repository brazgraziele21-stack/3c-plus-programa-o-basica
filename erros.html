Não usar <!DOCTYPE html> no início do documento.

Escrever tags erradas ou com nomes incorretos.

Esquecer de fechar tags corretamente.

Colocar elementos no lugar errado da estrutura.

Esquecer o atributo alt nas imagens.

Aninhar tags de forma incorreta ou inadequada.

Usar muitas tags <br> para espaçamento.

Não usar a estrutura básica (html, head e body).

Esquecer de definir o título da página com a tag <title>.

Usar nomes de arquivos e caminhos incorretos em links e imagens.

Checklist:
Usei <!DOCTYPE html> no início do documento.
Escrevi as tags corretamente.
Fechei todas as tags corretamente.
Coloquei os elementos nos lugares corretos da estrutura.
Adicionei o atributo alt nas imagens.
Aninhei as tags de forma correta.
Evitei usar muitas tags <br> para espaçamento.
Usei a estrutura básica (html, head e body).
Defini o título da página com a tag <title>.
Verifiquei se os nomes de arquivos e caminhos estão corretos.
